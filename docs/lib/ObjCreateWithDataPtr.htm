ObjCreateWithDataPtr [v2.1-alpha.36+]

Creates an object with an internal data pointer.

Obj := ObjCreateWithDataPtr(ClassObj, Address)

Parameters

ClassObj

Type: Object

A Class object which supports direct construction.

Address

Type: Integer

A number in the native integer range (32-bit or 64-bit). If ClassObj defines typed properties, the value must be either zero or a compatible memory address.

Return Value

Type: Object or Struct

The return value is an object derived from ClassObj.Prototype.

Error Handling

An exception is thrown if ClassObj is unsupported.

Passing an invalid non-zero address may cause program instability if ClassObj defines any typed properties.

Remarks

Consider all alternatives before using this function. It is intended for specific unusual cases such as:

  • Implementing abstractions for function pointers, interface pointers, handles and similar, where Obj itself represents the pointer or handle value, like a boxed pointer, but with __Delete enabled.
  • Creating a non-struct object whose typed properties reference memory outside the object itself.

This function should not be used merely to bypass an overridden static Call method. Within the method, call super() or super.Call() to construct an instance. An overridden method can also be bypassed by explicitly invoking its superclass version, as in (Object.Call)(ClassObj).

Unlike ClassObj.Call, this function creates an object without calling __Init or __New, but the script can call them manually if desired. If __Init is not called, instance variable initializers are not executed. The end result is similar to an expression like {Base: ClassObj.Prototype}, except that a wider range of classes are supported.

Unlike StructClass.At, __Delete is called when the object is deleted.

The object's data pointer can be retrieved with ObjGetDataPtr and set with ObjSetDataPtr. If ClassObj is a struct class, it can also be retrieved with Obj.Ptr.

Examples

Create a reference-counted callback.

#Requires AutoHotkey v2.1-alpha.36

myCallback := CCallback(() => MsgBox("Callback was called"))

; Callback can be assigned to a pointer field.
sample := SampleStruct()
sample.callback := myCallback

; Just to show we don't need to keep this reference:
myCallback := unset

; Call the callback (a better example would pass it via struct to an API).
DllCall(NumGet(sample, IntPtr))

sample := unset
MsgBox "Variables have been unset"

struct SampleStruct {
    callback : CCallback.Ptr
}

struct CCallback {
    static Call(args*) {
        cb := CallbackCreate(args*)
        MsgBox "Creating callback " cb
        return ObjCreateWithDataPtr(this, cb)
    }
    __delete() {
        MsgBox "Deleting callback " this.ptr
        CallbackFree(this.ptr)
    }
}
