HTML Help Workshop
------------------

Microsoft's HTML Help Workshop is a development tool used to compile
individual HTML files, images, and navigation data into a single,
compressed .chm (Compiled HTML Help) file.

Installation Instructions
-------------------------

In order to generate documentation in CHM format, you must first
install HTML Help Workshop:

1. Run htmlhelp.exe (preferably as administrator)

2. Accept the End User License Agreement (EULA) by clicking "Yes".

3. When prompted to install HTML Help Workshop, click "Yes".

4. Choose the installation directory. It's best to leave it as it is.
   Default location: C:\Program Files (x86)\HTML Help Workshop

5. If the unimportant warning is displayed stating that "this computer
   already has a newer version of HTML Help", click "OK".
   This warning can safely be ignored.

6. Complete and close the setup wizard by clicking "OK".

HTML Help Documentation
-----------------------

helpdocs.zip includes the following files:

- htmlhelp.chm (HTML Help Authoring Guide)
  Shows how to plan, create, and compile Help projects using HTML
  Help Workshop.

- Viewhlp.chm (Help for the HTML Help Viewer)
  A redistributable set of topics that provide help for the HTML
  Help viewer. These can be customized according to your needs.

- htmlref.chm (HTML Reference)
  A basic HTML reference for Help authors.

- hhaxref.chm (HTML Help ActiveX Control Reference)
  Explains the parameters, commands, and methods of the HTML Help
  ActiveX Control.

- htmlhelp.lib (HTML Help API Library File)
